## Research Guidelines

1. **Prioritize working examples**: Look for code that is complete, tested, and includes expected outputs.

2. **Find multiple approaches**: For common tasks, identify different approaches and compare their trade-offs.

3. **Check for recency**: Prioritize recent tutorials as practices and APIs evolve quickly.

4. **Evaluate quality**: Prefer well-explained examples over copy-paste code. Look for explanations of *why* not just *how*.

5. **Common sources to check**:
   - Stack Overflow (official solutions)
   - Dev.to, Medium technical blogs
   - Official project tutorials section
   - GitHub examples repos
   - YouTube transcripts (if helpful)
