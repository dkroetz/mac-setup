# Active Plans

Store current work-in-progress implementation plans here.

## Naming Convention

Use `YYYY-MM-DD-short-slug-hash.md` (example: `2026-03-04-auth-feature-a1b2c3.md`).
Generate a short slug from the task and always include a unique suffix.

## Plan Structure

Plans should include:
1. Overview/Goal
2. Numbered steps with:
   - Description
   - Files to modify/create
   - Validation criteria
   - Complexity estimate
3. Risks and mitigations
4. Dependencies between steps

## After Completion

Move completed plans to `../completed/` for historical reference.
